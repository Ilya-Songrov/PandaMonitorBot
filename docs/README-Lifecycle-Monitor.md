# Lifecycle Monitor - Моніторинг життєвого циклу комп'ютера

## Опис

Lifecycle Monitor автоматично відстежує коли комп'ютер вмикається і вимикається, збираючи статистику використання.

## Як працює

### При старті бота (комп'ютер увімкнено):
1. Записує час старту в `logs/session_history.json`
2. Зчитує час останньої активності з `logs/lifecycle_data.json`
3. Розраховує час простою (downtime)
4. Надсилає повідомлення з статистикою за поточний день
5. Запускає періодичне оновлення активності кожні `MONITOR_INTERVAL` секунд

### Під час роботи:
- Кожні `MONITOR_INTERVAL` секунд оновлює файл `logs/lifecycle_data.json` з поточним часом
- Це дозволяє відстежувати останню активність бота

### При зупинці бота (комп'ютер вимикається):
- Записує час завершення в `logs/session_history.json`
- Не надсилає повідомлень (бот вже не працює)

### При наступному запуску:
- Зчитує час з `logs/lifecycle_data.json` як час останнього вимкнення
- Показує статистику за поточний день

## Структура даних

### logs/lifecycle_data.json
```json
{
  "last_activity": "2025-10-25T01:30:45.123456",
  "computer_name": "MyComputer"
}
```

### logs/session_history.json
```json
[
  {
    "startup": "2025-10-25T08:00:00.000000",
    "shutdown": "2025-10-25T12:30:00.000000",
    "computer_name": "MyComputer"
  },
  {
    "startup": "2025-10-25T14:00:00.000000",
    "shutdown": null,
    "computer_name": "MyComputer"
  }
]
```

## Приклад повідомлення при старті

```
🟢 MyComputer запущено!

📅 Поточний старт: 2025-10-25 14:00:00
⏱️ Час простою: 1г 30м

📊 Статистика за сьогодні:
• Кількість сесій: 2
• Перший запуск: 08:00:00
• Загальний час роботи: 4г 30м

Використовуйте /help для перегляду команд.
```

## Команди

### `/lifecycle_status`
Показує поточний статус lifecycle монітора та статистику за день:
- Поточний час старту
- Час останнього вимкнення
- Кількість сесій за день
- Загальний час роботи за день
- Час першого запуску

## Налаштування

Інтервал оновлення активності контролюється параметром `MONITOR_INTERVAL` в `.env`:
```bash
MONITOR_INTERVAL=60  # секунди
```

## Особливості

- ✅ Автоматично працює при старті/стопі бота
- ✅ Не потребує ручного ввімкнення
- ✅ Зберігає історію сесій
- ✅ Розраховує статистику за поточний день
- ✅ Відстежує час простою між сесіями
- ✅ Працює навіть при аварійному завершенні (використовує час з lifecycle_data.json)

## Обмеження

- Повідомлення про вимкнення не надсилаються (бот вже не працює)
- Статистика обнуляється щодня (показує тільки поточний день)
- При аварійному завершенні час shutdown може не записатися
